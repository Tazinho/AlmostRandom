## Projects and R software

### snakecase

An R package for parsing strings and converting naming conventions, including snake_case and lowerCamelCase. The tutorial describes \`to_any_case()\` as its central function and covers output separators, abbreviations, special input characters, parsing options, and transliterations. Example uses include renaming imported data, preparing readable graphics labels, and adapting names for export. The tutorial advises checking automatic conversion results.

## Blog topics

### Adding a free AI chatbot to a blogdown website — 28 September 2026

[Read the post](https://www.malte-grosser.com/post/adding-a-free-ai-chatbot/).

Malte describes adding an AI assistant to Almost Random with help from ChatGPT. Codex prepared a compact website-context document from the local repository. The post shares his experience and implementation choices rather than presenting a universal tutorial.

The setup uses a JavaScript/CSS chat window on a blogdown/Hugo Academic website, a Cloudflare Worker, and Cloudflare Workers AI with Google's Gemma 4 model (\`@cf/google/gemma-4-26b-a4b-it\`). He chose Cloudflare following ChatGPT's suggestion because it combines the backend and model access and stops requests when the Free-plan allowance is exhausted. He did not benchmark answer quality across providers.

The system prompt restricts answers to supported website information. The prompt and context are pasted directly into the Worker; they are not fetched automatically from the repository. Significant website updates require updating the context, replacing the text in the Worker and redeploying it.

The article also covers desktop and mobile design, input limits, safe Markdown rendering, and maintenance. The described interface sends only the latest question to the model, despite displaying earlier messages. Provider comparisons and free allowances reflect the article's September 2026 review and should not be presented as permanently current.

### Data dictionaries for humans, agents and jumping frogs — 23 September 2026

[Read the post](https://www.malte-grosser.com/post/data-dict-jumping-frogs/).

Topics include data documentation, measurement definitions, table relationships, validation rules, agent-assisted drafting, human review, and providing context to AI agents. Frog-jumping and sea-otter datasets illustrate the importance of understanding what was measured; the post also discusses animal-welfare context. It introduces Data Dict and mentions querychat, dbt documentation and tests, and the Open Data Contract Standard.

The post describes [Data Dict](https://data-dict.tidyverse.org/) as an open-source project initiated by Hadley Wickham and supported by Posit, designed for teams working across R, Python, and SQL. This is third-party software discussed by Malte, not a project attributed to him. Descriptions of its capabilities reflect the dated post.
